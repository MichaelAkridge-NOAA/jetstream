📝 Setup Instructions

Option 1: User Authentication (Recommended)

Authenticate using your Google Cloud account:

gcloud auth application-default login

✓ Simplest method - uses your Google account
✓ No service account keys needed
✓ Works on your local machine

Option 2: Service Account (Production)

Set environment variable with service account JSON:

# PowerShell
$env:GOOGLE_APPLICATION_CREDENTIALS="C:\path\to\service-account.json"

Download service account key from Google Cloud Console
