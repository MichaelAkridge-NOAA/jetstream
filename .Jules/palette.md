## 2026-05-09 - [Tooltips for TUI Accessibility]
**Learning:** Textual's `Button` widgets support a `tooltip` attribute which is essential for icon-only buttons in terminal UIs to provide context and improve accessibility. Screen readers in TUIs often rely on these tooltips to announce the function of an element.
**Action:** Always include descriptive tooltips for icon-only buttons or buttons with concise labels to guide users and improve accessibility.
